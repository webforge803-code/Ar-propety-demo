# AR Property — Demo

Ini ialah versi portable untuk demo client.

## Jalankan di komputer
```bash
npm install
npm run dev
```

## Deploy
Boleh upload repo ini ke GitHub dan import ke Vercel/Netlify.

Nota: Versi ini mengekalkan UI/flow asal, tetapi Firebase ditanggalkan supaya demo boleh berjalan tanpa konfigurasi Firebase. Leads dan perubahan listing hanya disimpan sementara dalam browser/session React.
